# AntigravityLab: El Bufón Semiótico 🃏🤖

Este repositorio es el laboratorio central donde convergen la programación en Python, el análisis semiótico y la exploración de modelos de lenguaje (LLMs).

## 🧩 Sobre el Proyecto
El Bufón Semiótico es un ecosistema de crítica literaria agéntica diseñado para la relectura de ficciones breves. A través de la emulación de conciencias literarias (Arlt, Sábato, Kafka, entre otros), el agente genera análisis críticos y permite al usuario establecer un diálogo dialéctico con estas 'sombras virtuales', culminando en la generación de reportes técnicos y el intercambio colaborativo 

## 🛠 Stack Tecnológico
* **Lenguaje:** Python
* **IDE:** Antigravity / Cursor
* **Ecosistema:** Vibe Coding + Docker para servicios MCP
* **Hardware de origen:** "The Specimen" (Intel i7-8700 | RTX 4070 Ti Super)

## 🎹 Filosofía del Desarrollador
Nacido en Buenos Aires (1965), este proyecto refleja una visión ecléctica que une la música analógica (Ableton Live, Prophet '08) con la vanguardia de las redes neuronales. Buscamos aquí poner en tensión las observaciones más sólidas sobre la inteligencia artificial.
